AAEGIS AI AUDIT

Evidence before verdict.

Aegis discovers technical facts, normalizes them into immutable evidence, maps that evidence to canonical controls, compares applicable requirements, challenges each conclusion, and produces a reproducible report. It provides decision support—not legal certification or a SOC attestation.

Local-first collectionVersioned baselinesDeterministic scoringIndependent verification

Current system and algorithm handling

One reusable pipeline serves project audits, batch processing, security reviews, and proposed-design analysis

ONE ALGORITHM
NOW

Prototype execution

The browser renders mock evidence and results. File selection remains local; it does not parse or transmit document contents. Baseline refresh and agent execution are simulated state transitions.

TARGET

Production execution

The same stage contracts call sandboxed parsers and scanners, normalized evidence storage, canonical policy mappings, deterministic scoring, and independent verification.

UNKNOWN

Uncertainty handling

Missing answers and unreadable evidence create typed unknowns and discovery tasks. They never become an automatic pass or fail and reduce confidence until verified.

CHANGE

Baseline handling

Official sources are checked before each run. The accepted manifest is pinned; new rules create a new baseline and never silently change a completed report.

CONFLICT

Contradiction handling

Machine evidence outranks documentation. Conflicting evidence is retained, marked for adversarial evaluation, and escalated when confidence stays below threshold.

REUSE

No duplicate analysis

Single, batch, security, and design workflows reuse SourceManifest, EvidenceGraph, ControlMap, ControlResult, Verification, and ReportSnapshot contracts.

Audit playbook

Nine stages from source connection to remediation verification

ALGORITHM v1.0
01
Scope & applicability

Identify system purpose, jurisdictions, industry, AI role, data subjects, deployment geography, and selected frameworks. Requirements outside the declared scope become not applicable—not passed.

AuditRequest
02
Source manifest

Inventory files, commits, dependencies, infrastructure, policies, schemas, models, datasets, APIs, streams, stores, and deployment descriptors. Hash every artifact and preserve exclusions.

SourceManifest
03
Architecture & data-flow discovery

Detect services, trust boundaries, identity paths, data stores, Kafka or streaming flows, training/inference pipelines, model registries, external processors, and regional movement.

AssetGraph
04
Deterministic collection

Run policy-as-code, SBOM, secret, IaC, configuration, access, encryption, dependency, and lineage checks before using AI reasoning.

RawEvidence[]
05
Evidence normalization

Convert scanner output into typed facts with source, digest, collector version, observation time, classification, confidence, and tenant boundary.

EvidenceGraph
06
Canonical control mapping

Map one technical fact to shared controls, then map those controls to versioned GDPR, HIPAA, SOC 2, ISO, NIST, EU AI Act, PCI, and CCPA requirements.

ControlMap
07
Evaluation & scoring

Apply applicability, evidence freshness, confidence, severity, and critical-control caps. Missing evidence is unknown, never automatically pass or fail.

ControlResult[]
08
Adversarial verification

Blindly re-check all critical failures, low-confidence decisions, and a sample of passes using separate evidence selection and evaluation strategy.

Verification[]
09
Report, remediate, re-test

Create an immutable snapshot with evidence links, verdicts, uncertainty, owners, recommended code and tools. Re-run affected controls after remediation.

ReportSnapshot
